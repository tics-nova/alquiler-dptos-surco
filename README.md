# Página Web - Departamentos en Alquiler

## Condominio Esencial - Santiago de Surco, Perú

Esta es la página web oficial para el alquiler de departamentos en el Condominio Esencial, ubicado en Av. Guardia Civil Norte 665, Santiago de Surco, Perú.

### Características de la Página Web:

- **Diseño Responsive**: Se adapta perfectamente a móviles, tablets y desktop
- **6 Páginas Completas**: Inicio, ambos departamentos, ubicación, condiciones y contacto
- **Integración con WhatsApp**: Enlaces directos para contacto inmediato
- **Mapas Interactivos**: Google Maps integrado para ubicación
- **Galería de Fotos**: Con las imágenes reales de los departamentos
- **Formulario de Contacto**: Se conecta directamente con WhatsApp
- **SEO Optimizado**: Títulos, meta tags y estructura para buscadores

### Despliegue en GitHub Pages:

1. Sube todos estos archivos a un repositorio de GitHub
2. Ve a Settings > Pages
3. Selecciona "Deploy from a branch"
4. Elige "main" branch y "/ (root)"
5. Tu página estará disponible en: `https://tu-usuario.github.io/nombre-del-repositorio`
